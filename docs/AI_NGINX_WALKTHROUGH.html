AI Server กับ nginx

กด “ถัดไป” ไปทีละขั้น · ← → เลื่อน · Space เล่นเอง · กล่องเส้นแดง = คำขอที่ถูกปฏิเสธ

ลองเอง: URL นี้ไปห้องไหน ตัวจำลองกติกาของ nginx.conf

พิมพ์ path แล้วดูว่า nginx ไล่เช็คอะไรบ้าง หรือกดตัวอย่าง

    ลองเอง: ยิง login รัว ๆ rate=10r/m · burst=5 · nodelay

    แต่ละ IP มี “ถัง” จุได้ 5 ครั้งเกินโควตา ถังรั่วออก 1 ครั้งทุก 6 วินาที ครั้งไหนทำให้ถังล้น → 429

    ลองเอง: ลบ noise ทีละรอบ ภาพจำลองแนวคิด ไม่ใช่โมเดลจริง

    ในของจริง seed ต่างกันจะได้ภาพปลายทางคนละภาพ ตัวจำลองนี้ใช้ภาพปลายทางเดียวเพื่อให้เห็นขั้นตอนชัด ๆ
